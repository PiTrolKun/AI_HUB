# ТЗ — подготовка .NET/WPF окружения

Дата: 2026-05-30

## Цель

Проверить, подходит ли выбранный стек `C# / .NET / WPF`, и подготовить минимально нужное окружение для первого WPF-каркаса AI_HUB.

## Границы задачи

Входит:

- проверить наличие `dotnet`, WPF-шаблонов, PowerShell 7, Git и winget;
- установить недостающий .NET SDK;
- проверить сборку временного WPF-проекта;
- зафиксировать зависимости в `REESTR.md`;
- обновить живой контекст и журнал отката.

Не входит:

- создание основного `.sln` / `.csproj`;
- создание WPF-кода AI_HUB;
- выбор UI-архитектуры;
- установка Visual Studio;
- установка backends, моделей или SQLite-пакетов.

## Выполненные действия

- Подтверждён стек `C# / .NET / WPF`.
- Проверено, что до установки был .NET runtime 8, но не было SDK.
- Установлен Microsoft .NET SDK 10.0.300 через winget.
- Проверено, что установлены runtime-компоненты `Microsoft.NETCore.App 10.0.8` и `Microsoft.WindowsDesktop.App 10.0.8`.
- Проверено, что WPF-шаблон доступен.
- Временный WPF-проект на `net10.0-windows` успешно собран.

## План проверки

- `dotnet --info`
- `dotnet new list wpf`
- `winget list --id Microsoft.DotNet.SDK.10 --exact`
- временный `dotnet new wpf` + `dotnet build`
- scanner кириллицы

## Критерии приёмки

- `dotnet --info` показывает SDK 10.0.300.
- WPF-шаблон доступен.
- Временная WPF-сборка проходит без ошибок.
- Реестр зависимостей обновлён.
- Откат зафиксирован в `BACKUP_ОТКАТ.md`.
