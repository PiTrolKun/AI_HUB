# ТЗ: страница начала работы

Дата: 2026-05-31

## Цель

Добавить в AI HUB новую страницу внутри основного окна, которая открывается по кнопке `Начать работу`.

Страница должна стать входной точкой для будущих рабочих режимов программы.

## Основное решение

Не открывать отдельное окно.

Сделать новую страницу внутри текущего `MainWindow`, по тому же принципу, как сейчас работает страница настроек.

## Поведение кнопки `Начать работу`

Если настройка завершена:

- кнопка `Начать работу` на главной странице открывает страницу `Начало работы`;
- нижняя строка статуса обновляется под новый сценарий.

Если настройка не завершена:

- остаётся текущее поведение `Начать настройку`.

## Страница `Начало работы`

На странице показать:

- заголовок `Начало работы`;
- пояснение: `Выберите новый режим работы`;
- блок `Новый проект`;
- один доступный режим: `Рассуждение / изучение`;
- кнопку выбора режима;
- кнопку `Назад`.

## Первый режим

Пока добавить только один режим:

`Рассуждение / изучение`

Описание:

`Разобрать тему, задать вопросы, изучить материалы, вести рабочий диалог и сохранять результаты.`

Кнопка:

`Выбрать режим`

Пока кнопка не запускает реальный AI-режим, а показывает статус-заглушку:

`Режим "Рассуждение / изучение" будет подключён следующим этапом.`

## Ранее начатое

Внизу страницы добавить сворачиваемый блок:

`Ранее начатое`

Требования:

- изначально блок свернут;
- при раскрытии показывать пример-заглушку будущего проекта;
- кнопка `Продолжить` пока неактивна или показывает статус-заглушку;
- реальные сохранённые проекты пока не подключать.

Пример текста внутри раскрытого блока:

`Пример будущей записи`
`Изучение: "Как выбрать локальную AI-модель"`
`Последнее открытие: сегодня`

## Что пока не делаем

- Не создаём реальные проекты/сессии.
- Не подключаем AI.
- Не добавляем режимы `Документы`, `Фото`, `Видео` до их реальной реализации.
- Не создаём базу проектов.
- Не меняем формат текущих настроек хранения.
- Не трогаем установщик, кроме обычной проверки сборки.

## Локализация

Все новые видимые строки добавить в:

- `ru.json`;
- `en.json`.

Перед закрытием ТЗ проверить совпадение ключей.

## Версия

После реализации повысить версию с `0.0.14-dev` до `0.0.15-dev`.

## Проверки

- `dotnet build`;
- scanner кириллицы;
- проверка совпадения ключей `ru.json` / `en.json`;
- запуск приложения;
- проверить, что `Начать работу` открывает страницу начала работы;
- проверить кнопку `Назад`;
- проверить раскрытие/сворачивание `Ранее начатое`;
- проверить русский и английский интерфейс.
