# ТЗ: менеджер основного ядра Qwen3 8B

Дата: 2026-05-31

## Цель

Добавить в AI HUB базовую логику основного ИИ-ядра проекта.

Основное ядро проекта:

`Qwen3 8B Q4_K_M`

Это не тяжёлая максимальная модель, а быстрый диспетчер AI HUB:

- понимать задачу;
- вести сценарий;
- работать с будущей RAG-памятью;
- выбирать инструменты;
- объяснять пользователю варианты.

Страдать ради качества можно будет на тяжёлых моделях-инструментах, но основное ядро должно комфортно работать на среднем игровом ПК уровня:

```text
i5
RTX 3060
16 ГБ RAM
```

## Основное решение

Не вшивать модель в основной установщик.

Основной установщик остаётся лёгким.

`Qwen3 8B Q4_K_M` скачивается через программу в выбранную папку моделей.

## Проверенный источник модели

Официальный источник:

- Hugging Face: `Qwen/Qwen3-8B-GGUF`
- файл: `Qwen3-8B-Q4_K_M.gguf`
- размер: `5027783488` байт, около `5.03 ГБ`;
- лицензия: `apache-2.0`;
- commit модели на момент фиксации ТЗ: `7c41481f57cb95916b40956ab2f0b139b296d974`;
- ETag/hash файла на момент фиксации ТЗ: `d98cdcbd03e17ce47681435b5150e34c1417f50b5c0019dd560e4882c5745785`.

Перед реализацией скачивания повторно проверить метаданные источника, потому что upstream-файл может измениться.

## Поведение после сохранения настроек

После нажатия `Сохранить` на странице настройки:

1. программа сохраняет настройки;
2. проверяет выбранную папку моделей;
3. если `Qwen3 8B Q4_K_M` не найден, показывает подтверждение:

```text
Настройки сохранены.
Основное ядро Qwen3 8B Q4_K_M не найдено.
Скачать сейчас?

[Скачать] [Открыть настройки] [Позже]
```

Скачивание начинается только после явного подтверждения пользователя.

## Поведение при запуске

При каждом запуске AI HUB:

1. проверить, выбрана ли папка моделей;
2. если папка не выбрана — предложить открыть настройки;
3. если папка выбрана, но `Qwen3 8B Q4_K_M` не найден — предложить:
   - скачать ядро;
   - открыть настройки;
   - отложить;
4. если ядро найдено и проверено — разрешить рабочий сценарий.

## Нижняя панель загрузки

При скачивании внизу окна появляется панель прогресса:

```text
Статус: скачивается основное ядро Qwen3 8B Q4_K_M
[████████░░░░░░░░░░] 42%   2.1 / 5.0 ГБ   12.3 МБ/с
[Пауза] [Отмена]
```

В первой реализации панель должна быть рабочей, а не декоративной.

Требования:

- показывать проценты;
- показывать скачано / всего;
- показывать скорость;
- показывать статус;
- поддержать отмену;
- по возможности поддержать паузу или хотя бы безопасную отмену с сохранением частичного файла для будущего продолжения.

## Проверки модели

Программа должна различать:

- модель не найдена;
- файл частично скачан;

- скачивание оборвалось;

- Не подключаем реальный backend запуска.
- Не запускаем `Qwen3 8B`.
- Не делаем полноценный Model Manager.
- Не делаем общий каталог моделей.
- Не делаем RAG.

## Важные правила

- Не скачивать модель без подтверждения пользователя.
- Не считать ядро установленным только по имени файла.
- Не удалять модели без прямого подтверждения.
- При отключённом диске или удалённой папке предлагать настройки.
- Если скачивание оборвалось, позже предлагать продолжить.
- Основной установщик не должен включать большие модели.
- Тестовый установщик не собирать без отдельной команды пользователя, если тест установленной версии не критичен.
