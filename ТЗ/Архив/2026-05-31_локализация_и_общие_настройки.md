# ТЗ: базовая локализация интерфейса и общие настройки

Дата: 2026-05-31

## Цель

Заложить в AI HUB простую файловую систему локализации, чтобы программа могла работать минимум на русском и английском языках.

Русский остаётся основным языком проекта.

## Основное решение

Использовать простые JSON-файлы локализации:

- `Исходники/AIHub/Localization/ru.json`;
- `Исходники/AIHub/Localization/en.json`.

В будущем пользовательские переводы можно будет добавлять вручную:

`%LOCALAPPDATA%\AI_HUB\Localization\<language>.json`

Если в выбранном языке нет строки:

1. пробуем выбранный язык;
2. если ключа нет, берём русский;
3. если и в русском нет ключа, показываем сам ключ.

## Страница настроек

В верхней панели рядом с кнопкой темы добавить кнопку настроек:

- без текста;
- значок шестерёнки;
- tooltip;
- открывает страницу настроек внутри основного окна.

На странице настроек пока реализовать только:

- заголовок `Настройки`;
- блок `Язык интерфейса`;
- выбор языка:
  - `Русский`;
  - `English`;
- кнопка `Назад`.

Выбор языка сохранять в:

`%LOCALAPPDATA%\AI_HUB\settings.json`

## Определение языка Windows

При первом запуске:

- если Windows на русском, использовать русский;
- если Windows на английском, предложить английский интерфейс;
- если язык Windows другой и перевода нет, оставить русский;
- выбор пользователя сохранить.

## Что переводим сразу

Перевести все текущие видимые строки интерфейса:

- заголовки стартовой страницы;
- кнопки;
- статусы;
- блоки настройки;
- подписи полей;
- tooltips;
- страницу настройки;
- сообщения рабочего режима в UI.

Системные имена файлов, внутренние технические логи и пути не переводить.

## Правило проекта

Добавить в `AGENTS.md` и `CODEX.md` правило:

После завершения каждого ТЗ перед архивацией и публикацией в GitHub нужно проверить английскую базу локализации. Если появились новые русские user-facing строки, нужно добавить соответствующие ключи в `en.json`. Только после этого выполнять commit/push.

## Что пока не делаем

- Не подключаем AI-перевод на лету.
- Не переводим ответы будущих AI-моделей через эту систему.
- Не делаем полноценную страницу всех настроек.
- Не добавляем десятки языков.
- Не делаем RTL-языки.
- Не делаем установщик языковых пакетов.
