# ТЗ: системная тёмная рамка окна Windows

Дата: 2026-05-30

## Цель

Сделать так, чтобы системный заголовок и рамка окна AI HUB лучше подчинялись теме Windows. На текущем этапе использовать стандартные возможности Windows и не рисовать собственный заголовок окна.

## Область работ

- Оставить стандартную рамку WPF/Windows.
- Добавить поддержку системного тёмного заголовка через Windows DWM API.
- При запуске приложения брать начальную тему из настройки Windows для приложений.
- При ручном переключении темы в AI HUB синхронно менять и системный заголовок окна.
- Не добавлять внешние зависимости.
- Не менять основной визуальный макет стартового окна.

## Технический подход

- Использовать `DwmSetWindowAttribute`.
- Основной атрибут: `DWMWA_USE_IMMERSIVE_DARK_MODE`.
- Для совместимости попробовать современный номер атрибута и fallback для старых сборок Windows.
- Получать `HWND` окна после создания источника окна WPF.
- Читать настройку Windows из ветки:
  - `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize`
  - параметр `AppsUseLightTheme`

## Ограничения

- Windows может по-разному применять цвет рамки на разных версиях Windows 10/11.
- Мы просим систему включить тёмный заголовок, но не управляем каждым пикселем заголовка.
- Полностью кастомный заголовок в это ТЗ не входит.

## Версия

После реализации повысить версию с `0.0.4-dev` до `0.0.5-dev`.

- `dotnet build`
- `Инструменты/check-cyrillic-integrity.ps1`
- Запуск приложения через текущий exe или стартовый скрипт.
- Smoke-проверка: окно стартует с заголовком `AI HUB 0.0.5-dev`.
- Smoke-проверка: переключение темы не роняет приложение.
