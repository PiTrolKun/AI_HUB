# ТЗ — первая публикация проекта на GitHub

Дата: 2026-05-30

## Цель

Подключить локальную папку `H:\AI_HUB` к репозиторию `https://github.com/PiTrolKun/AI_HUB` и отправить первый безопасный коммит.

## Границы задачи

Входит:

- установить GitHub CLI, если отсутствует;
- подготовить `.gitignore`;
- подготовить `.gitattributes`;
- инициализировать Git в `H:\AI_HUB`;
- настроить ветку `main`;
- подключить remote `origin`;
- сделать первый коммит;
- отправить коммит в GitHub после успешной авторизации.

Не входит:

- создание WPF-приложения;
- публикация release;
- настройка GitHub Actions;
- удаление backup-ов;
- превращение репозитория в публичный, если он создан приватным.

## Важные правила

- Не публиковать содержимое `Backups`, кроме `Backups/README.md`.
- Не публиковать runtime-данные, кроме README-заглушек.
- Не публиковать secrets, ключи и локальные `.env`.
- Перед push запустить scanner кириллицы.

## План проверки

- `git status --short`
- `git status --ignored --short`
- `powershell -ExecutionPolicy Bypass -File .\Инструменты\check-cyrillic-integrity.ps1`
- `git remote -v`
- `git log --oneline -1`
- после push: проверить `https://github.com/PiTrolKun/AI_HUB`

## Критерии приёмки

- В `H:\AI_HUB` создан Git-репозиторий.
- Первый коммит содержит проектные документы и README-заглушки.
- Backup-содержимое и runtime-данные не попали в коммит.
- Remote указывает на `https://github.com/PiTrolKun/AI_HUB.git`.
- Коммит отправлен на GitHub.

## Backup / rollback

Документальные изменения сохранены в `Backups/20260530_200837_github_initial_publish_docs`.

Если нужно отменить локальную Git-инициализацию до push, удалить папку `.git`. После push откат делается отдельным коммитом, а не переписыванием истории без явного решения пользователя.
