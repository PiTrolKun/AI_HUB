# ТЗ: тестовый установщик AI_HUB через Inno Setup

Дата: 2026-05-31

## Цель

Сделать первый повторяемый способ сборки тестового установщика AI_HUB, чтобы пользователь мог самостоятельно собрать `.exe` установщик двойным кликом и перенести его на другой ПК для проверки.

## Выбранный вариант

Использовать Inno Setup.

Причины:

- обычный понятный `.exe` установщик Windows;
- умеет создавать ярлыки и uninstall;
- подходит для WPF/.NET приложения;
- хорошо автоматизируется скриптом;
- проще MSIX/WiX на текущем этапе.

## Размещение

Тестовые установщики сохранять в:

`H:\AI_HUB\Тесты\Установщики`

Временную publish-папку приложения создавать в:

`H:\AI_HUB\Runtime\Publish\AIHub-win-x64`

Скрипты:

- `H:\AI_HUB\Собрать_установщик_AI_HUB.cmd` — запуск двойным кликом;
- `H:\AI_HUB\Инструменты\build-installer.ps1` — основная логика сборки;
- `H:\AI_HUB\Инструменты\Installer\AI_HUB.iss` — Inno Setup сценарий.

## Поведение сборки

Скрипт должен:

1. Прочитать версию из `VERSION`.
2. Выполнить `dotnet publish` для WPF-проекта.
3. Собрать self-contained `win-x64` publish, чтобы на тестовом ПК не требовать заранее установленный .NET Runtime.
4. Найти `ISCC.exe` Inno Setup.
5. Если Inno Setup не установлен, вывести понятное сообщение и команду установки через `winget`.
6. Если Inno Setup найден, собрать установщик в `Тесты\Установщики`.
7. Назвать файл установщика с версией проекта, например:

`AI_HUB_Setup_0.0.13-dev.exe`

## Установщик

Первый установщик должен:

- устанавливать AI HUB для текущего пользователя без обязательных прав администратора;
- использовать название `AI HUB`;
- использовать текущую иконку приложения;
- создать ярлык в меню Пуск;
- предложить опциональный ярлык на рабочем столе;
- добавить стандартное удаление через Windows;
- после установки предложить запуск AI HUB.

## Что пока не делаем

- Не делаем автообновление.
- Не подписываем установщик сертификатом.
- Не публикуем GitHub Release.
- Не добавляем MSIX/WiX.
- Не переносим модели, backends и пользовательские данные в установщик.
- Не удаляем `%LOCALAPPDATA%\AI_HUB` при uninstall.

## Версия

После добавления первого установочного контура повысить версию с `0.0.12-dev` до `0.0.13-dev`.

## Инструменты

Inno Setup установлен по прямому подтверждению пользователя:

- пакет: `JRSoftware.InnoSetup`;
- версия: `6.7.3`;
- способ установки: `winget`.

## Проверки

- `dotnet build`;
- `dotnet publish` через `build-installer.ps1`;
- scanner кириллицы;
- если Inno Setup установлен — сборка `.exe` установщика;
- если Inno Setup не установлен — понятное сообщение с командой установки;
- проверить, что `.cmd` запускает PowerShell-скрипт и оставляет окно открытым после завершения.

## Результат реализации

Созданы:

- `Собрать_установщик_AI_HUB.cmd`;
- `Инструменты/build-installer.ps1`;
- `Инструменты/Installer/AI_HUB.iss`;
- тестовый установщик `Тесты/Установщики/AI_HUB_Setup_0.0.13-dev.exe`.

Inno Setup 6.7.3 установлен через `winget` по прямому подтверждению пользователя.
