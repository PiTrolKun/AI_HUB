# ТЗ — стартовый скелет AI_HUB

Дата: 2026-05-30

## Цель

Создать полный стартовый скелет проекта AI_HUB: папки, служебные документы, проектную документацию, runtime-зоны и README-файлы.

## Границы задачи

Входит:

- корневые служебные документы;
- документация проекта;
- папки для ТЗ, backup, исходников, тестов, инструментов и каталогов;
- runtime-папки под модели, результаты, кэш, backends, индексы, логи и RAG;
- короткие README в важных папках.

Не входит:

- создание WPF-приложения;
- создание `.sln` и `.csproj`;
- SQLite-схема;
- скачивание моделей;
- установка backends;
- запуск внешних инструментов.

## Затрагиваемые области

- Корень `H:\AI_HUB`.
- `Документы_проекта`.
- `ТЗ`.
- `Runtime`.
- Рабочие папки будущего проекта.

## Риски

- Ошибка кодировки русских строк.
- Слишком ранняя фиксация неверной архитектуры.
- Смешивание runtime-данных и исходников.

## План проверки

- Проверить структуру через `Get-ChildItem -Recurse`.
- Выборочно прочитать ключевые документы.
- Проверить русские строки в файлах.
- Не запускать `dotnet restore/build/test`, потому что кодового проекта ещё нет.

## Критерии приёмки

- Все папки из плана созданы.
- Все основные документы созданы.
- Важные папки имеют `README.md`.
- `BACKUP_ОТКАТ.md` содержит запись об этой задаче.
- Существующие файлы не изменены.

## Backup / rollback

Существующие файлы не изменяются, поэтому backup существующих файлов не требуется.

Откат: удалить новые файлы и папки стартового скелета, не трогая `Инструкции` и `local_ai_hub_final_summary_ru.md`.
