# ТЗ — прототип стартового окна WPF

Дата: 2026-05-30

## Цель

Создать первый реальный визуальный прототип стартового окна AI_HUB, чтобы пользователь мог увидеть будущий первый запуск программы в живом WPF-окне.

## Границы задачи

Входит:

- создать минимальный WPF-проект в `Исходники`;
- сделать стартовое окно мастера первого запуска;
- добавить переключатель светлой и тёмной темы;
- исправить аварийное закрытие стартового окна, если оно проявится при запуске;
- добавить простой скрипт запуска по двойному клику;
- показать смысл первого шага: подготовка хранилища, результатов и проверки ПК;
- собрать проект;
- запустить окно для визуальной оценки;
- обновить историю проекта.

Не входит:

- каталог моделей;
- скачивание моделей;
- реальная проверка ПК;
- сохранение настроек;
- SQLite;
- backend manager;
- установщик;
- финальный дизайн.

## Визуальный ориентир

Окно должно быть спокойным, нативным и похожим на Windows 11 setup/wizard, а не на рекламную посадочную страницу.

Главные элементы:

- название `AI_HUB`;
- короткое объяснение, что программа подготовит локальную AI-мастерскую;
- три шага: хранилище моделей, результаты, проверка компьютера;
- две кнопки: `Начать настройку` и `Позже`;
- кнопка `Тёмная тема` / `Светлая тема` в правом верхнем углу;
- нижняя строка состояния с пометкой, что ничего не скачивается и не меняется без подтверждения.

## Запуск для проверки

Для ручного запуска без команд Codex создан файл:

- `Запустить_AI_HUB.cmd`

Пользователь может открыть его двойным кликом. `.cmd` запускает `start-aihub.ps1`, а PowerShell-скрипт собирает текущую dev-версию и запускает окно программы.

## План проверки

- `dotnet restore`
- `dotnet build`
- запуск WPF-приложения;
- запуск через `Запустить_AI_HUB.cmd`;
- проверка клика по кнопке темы через Windows UI Automation;
- scanner кириллицы.

## Критерии приёмки

- Проект собирается без ошибок.
- Окно запускается.
- Окно не закрывается аварийно сразу после запуска.
- Пользователь может запустить dev-версию двойным кликом по `Запустить_AI_HUB.cmd`.
- Русский текст отображается корректно.
- Светлая и тёмная тема переключаются без перезапуска окна.
- Визуал даёт понятное первое впечатление о программе.

## Backup / rollback

Backup документов создан в `Backups/20260530_203002_startup_window_prototype`.

Если прототип нужно откатить, удалить созданный WPF-проект из `Исходники` и восстановить изменённые документы из backup.
