# BRANDING — AI_HUB

Этот файл фиксирует правила использования названия, визуального образа и официального статуса проекта.

## Статус

Название `AI_HUB` используется как рабочее название проекта.

Официальный логотип, знак, финальное публичное название и правила использования бренда пока не утверждены.

## Предварительные правила

- Не выдавать сторонние сборки за официальные без явного разрешения автора проекта.
- Не использовать название и будущий логотип так, чтобы создавалось ложное впечатление официальной поддержки или партнёрства.
- Перед публикацией на GitHub уточнить, нужен ли отдельный `TRADEMARK.md`.
