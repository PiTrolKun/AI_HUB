# BRANDING — ЛОПАТА / LOPATA

Этот файл фиксирует правила использования названия, визуального образа и официального статуса проекта.

## Статус

Публичное название утверждено пользователем 2026-09-05: **ЛОПАТА / LOPATA**.

- Русский вариант: **ЛОПАТА — Локальная Оболочка Пользовательских Автономных Технологий и Ассистентов**.
- Английский вариант: **LOPATA — Local Offline Platform for AI Tools and Assistants**.
- В интерфейсе написание зависит от выбранного языка; в технических местах,
  где кириллица мешает совместимости, используется LOPATA.
- Пользователь сообщил о переименовании репозитория: https://github.com/PiTrolKun/LOPATA.

## Причина ребрендинга — 2026-09-05

Пользователь обнаружил в Microsoft Store раздел **AI Hub** и предоставил
скриншот. Совпадение с прежним рабочим названием AI_HUB стало причиной
выбора самостоятельного, узнаваемого публичного имени: ЛОПАТА / LOPATA.
Цель — избежать путаницы с разделом Microsoft Store и отличать наш проект.
По пояснению пользователя, решение не связано с юридическими претензиями.

Ребрендинг касается публичного имени и оформления. Существующая папка
`H:\AI_HUB`, пути к моделям и данным, настройки и внутренние технические
имена сохраняются. Исторические записи с прежним названием остаются историей.

Согласовано обновление стартового окна: предоставленная пользователем
картинка с расшифровкой названия будет общей для обоих языков, приветствие
и кнопки перемещаются в нижнюю часть левой колонки. Ребрендинг принят пользователем в 0.1.43-dev.

## Два визуальных образа: бренд и программа

Картинка с расшифровкой ЛОПАТА — лицо названия и бренда ЛОПАТА / LOPATA.
Монитор с матрицей — лицо самой программы, её сохраняемый логотип и значок.
Пользователь явно подтвердил 2026-09-05: при ребрендинге этот логотип не менять.

Файлы:

- исходный PNG: `Исходники/AIHub/Assets/logo_crt_black_hole_matrix_tight_transparent_1x1.png`;
- app/exe icon: `Исходники/AIHub/Assets/AppIcon.ico`;
- исходный материал пользователя: `Данные_для_внедрения/Фото/logo_crt_black_hole_matrix_tight_transparent_1x1.png`.

PNG содержит логотип программы, а AppIcon.ico — его вариант для значка программы,
exe, ярлыков и меню Пуск. Все перечисленные изображения сохраняются.
Картинка с расшифровкой «ЛОПАТА» представляет бренд на стартовом
окна и не заменяет монитор с матрицей. Подпись ярлыка относится к публичному
названию программы; сохранение значка не означает сохранение подписи AI HUB.

## Предварительные правила

- Не выдавать сторонние сборки за официальные без явного разрешения автора проекта.
- Не использовать название и логотип так, чтобы создавалось ложное впечатление официальной поддержки или партнёрства.
- Перед публикацией на GitHub уточнить, нужен ли отдельный `TRADEMARK.md`.
- При будущей сборке установщика сохранить `AppIcon.ico` с монитором и матрицей как источник значка exe, ярлыка рабочего стола и меню Пуск.
