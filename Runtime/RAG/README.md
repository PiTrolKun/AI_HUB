# Runtime / RAG

Будущая папка для локальной RAG-памяти AI_HUB.

Каждая будущая запись должна иметь паспорт происхождения:

- кто внёс запись;
- какой инструмент или модель;
- при каких обстоятельствах;
- источники;
- уровень доверия;
- тип записи;
- может ли запись влиять на будущие решения.

Модели могут предлагать записи, но не должны молча менять фундаментальные правила.
