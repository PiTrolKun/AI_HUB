# Runtime / Результаты

Будущая папка для результатов работы моделей и инструментов.

Правило безопасности: результаты пользователя удаляются только вручную или по прямому запросу пользователя.

Примеры будущих результатов:

- изображения;
- звук;
- музыка;
- видео-кадры;
- текстовые итоги;
- сохранённые материалы сессий.
