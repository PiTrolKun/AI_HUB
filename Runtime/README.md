# Runtime — AI_HUB

Эта папка зарезервирована под будущие runtime-данные локального AI-хаба.

Важно: в реальном приложении пользователь сможет выбирать диски и лимиты. Эта папка сейчас служит стартовой структурой проекта, а не окончательным обязательным местом хранения.

Категории:

- `Модели`;
- `Временные_модели`;
- `Результаты`;
- `Кэш`;
- `Backends`;
- `Индексы_документов`;
- `Логи`;
- `RAG`.

Результаты пользователя нельзя удалять автоматически без прямого подтверждения.
