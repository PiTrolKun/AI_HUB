# CONTEXTHUB — AI_HUB

Дата старта контекста: 2026-05-30

## Назначение

Этот файл — главный живой контекст проекта AI_HUB. Его нужно обновлять после значимых решений, крупных задач и изменений архитектуры.

## Текущая идея проекта

AI_HUB — русскоязычный локальный AI-хаб для Windows 11 в стиле проводника Windows.

Программа должна помогать пользователю находить, скачивать, запускать, хранить и использовать локальные бесплатные ИИ-модели без терминала, гайдов и ручной настройки.

## Главный пользовательский принцип

Пользователь не программист. Кодингом, настройкой структуры, проверками и техническими решениями занимается Codex.

## Текущий технический ориентир

- Платформа: Windows 11.
- Стек: C# / .NET / WPF.
- Локальные данные: SQLite в будущих этапах.
- Визуальная философия: Windows-проводник для локального ИИ.

## Ближайший MVP

Первый MVP: визуал + скачивание моделей.

В MVP должны войти:

- WPF-приложение в стиле проводника.
- Каталог моделей.
- Установленные модели.
- Скачивание моделей.
- AI-хранилище.
- Выбор дисков и лимитов.
- Статусы моделей.
- Ручное закрепление и удаление.
- Базовый паспорт ПК.

## Подтверждённые решения

- Проект начинается не с голосового ассистента, а с фундамента: визуал, каталог, скачивание, хранение.
- Основной будущий локальный интеллект: Qwen3 32B.
- Интернет для модели — инструмент хаба, а не свободный прямой доступ модели.
- Backends должны быть встроены или устанавливаться автоматически.
- Результаты пользователя нельзя удалять без прямого подтверждения.
- Закреплённые модели защищены от автоудаления.
- Перед крупной новой реализацией создаётся ТЗ в папке `ТЗ`.
