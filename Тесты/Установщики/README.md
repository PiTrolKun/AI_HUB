# Тестовые установщики AI_HUB

Эта папка предназначена для тестовых сборок установщика AI_HUB.

Сюда можно складывать:

- готовые `.exe` установщики для проверки на другом ПК;
- временные отчёты о тестовой установке;
- короткие заметки по проверке конкретной сборки.

Не хранить здесь:

- исходный код приложения;
- скачанные AI-модели;
- личные ключи, токены и пароли;
- большие временные файлы, которые можно пересобрать.

Текущий выбранный путь для будущего установщика: Inno Setup.
Для запуска сборки простым двойным кликом будет добавлена `.cmd`-обводка над PowerShell-скриптом.

Ожидаемое имя тестового установщика:

```text
AI_HUB_Setup_<версия>.exe
```

Например:

```text
AI_HUB_Setup_0.0.13-dev.exe
```
