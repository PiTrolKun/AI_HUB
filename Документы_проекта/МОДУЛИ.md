# Модули — AI_HUB

Этот файл перечисляет будущие модули проекта и их статус.

## MVP

| Модуль | Назначение | Статус |
|---|---|---|
| Shell / Main UI | Главное окно в стиле проводника | План |
| Model Catalog | Независимый накопительный каталог, background sync, PC/lineage-фильтр и structured tool; UI позже | Работает в сценарии |
| Installed Models | Учёт установленных моделей | План |
| Download Manager | Скачивание моделей | План |
| AI Storage | Диски, лимиты, категории хранения | План |
| PC Passport | Базовая оценка компьютера | План |

## После MVP

| Модуль | Назначение | Статус |
|---|---|---|
| Backend Manager | Установка и управление backend-ами | Будущее |
| RAG Memory | Общая локальная память системы | Будущее |
| Web Tool | Поиск и HTTP-доступ через инструмент хаба | Будущее |
| Voice Input | Голосовой старт задачи | Будущее |
| Session Knowledge Tree | Структурированное дерево решений, знаний и результата executor-сессии | Реализовано для «Режима неопределённости», ручной тест |
| Result Manager | Просмотр версионных Markdown-результатов и ручной экспорт итогового документа в DOCX | Частично реализовано для «Режима неопределённости» |
| Model Sleep Manager | Возможный сон/пауза модели при поддержке backend-а | Идея |
