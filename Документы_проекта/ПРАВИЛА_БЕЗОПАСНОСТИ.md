# Правила безопасности — AI_HUB

Этот документ фиксирует продуктовые правила безопасности.

## Данные пользователя

- Не удалять результаты пользователя без явного подтверждения.
- Не удалять закреплённые модели автоматически.
- Перед крупным скачиванием показывать прогноз места.
- Лимит AI-хаба не равен всему свободному месту на диске.

## Backends и инструменты

- Не скачивать и не запускать backends без понятного подтверждения пользователя.
- Не запускать скачанное без проверки источника и подтверждения.
- Не менять системные настройки Windows без подтверждения.
- Не выполнять опасные команды без подтверждения.

## Модели и доступ к системе

- Не давать моделям прямой бесконтрольный доступ к файлам, интернету, shell или системным настройкам.
- Все действия моделей через инструменты должны проходить через permission layer и логирование.
- Интернет для ядра — инструмент хаба, а не свободное блуждание модели.

## RAG и правила

- Важные правила не сохранять молча без подтверждения пользователя.
- RAG может уточнять решения, но не должен перебивать фундаментальные правила безопасности.
