# Архитектура — AI_HUB

Этот документ фиксирует архитектурные ориентиры. Он не заменяет ТЗ на конкретные задачи.

## Основной стек

- C#.
- .NET.
- WPF.
- SQLite для локальных данных на будущих этапах.

## Принципы

- Не превращать главное окно или главный сервис в монолит.
- Разделять UI, модели данных, сервисы, хранилище, adapters и backends.
- Долгие операции выполнять асинхронно.
- Не блокировать UI thread.
- Не хардкодить пути к моделям, backend-ам и runtime-данным, если есть настройки или discovery.

## Предварительные слои

- UI: WPF views и view models.
- Application services: сценарии пользователя.
- Domain models: модели предметной области.
- Storage: локальные настройки, каталог, статусы, будущая SQLite-база.
- Runtime adapters: доступ к backends и системным возможностям Windows.
- Safety/permissions: подтверждения опасных действий и логирование.

## MVP-ориентир

В первом MVP архитектура должна поддерживать каталог моделей, установленные модели, скачивание, AI-хранилище и базовый паспорт ПК.
