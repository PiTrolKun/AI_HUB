# Документы проекта — AI_HUB

AI_HUB — локальная AI-мастерская для Windows. Она объединяет модели, инструменты, профиль пользователя, паспорт ПК, безопасные разрешения, журналы и пошаговые сценарии в одном нативном интерфейсе.

Главная аудитория — человек, который хочет пользоваться локальным ИИ без терминала и ручной настройки каждого компонента.

## Текущее состояние

Уже работают:

- WPF-интерфейс, настройка хранилища и паспорт ПК;
- локальное ядро Qwen3 8B через llama.cpp;
- F12-диагностика, structured tools и JSONL-журналы;
- web/Hugging Face инструменты и reranker;
- изолированный накопительный каталог Hugging Face с посевным реестром и радаром популярных новинок;
- профиль пользователя и память контекста;
- первый боевой сценарий `Режим неопределенности` реализован и прошёл пользовательские гибридные проверки.

Текущий сценарий не решает вопрос пользователя и не проводит подробное предметное интервью. Он строит структурированный профиль необходимых возможностей, проверяет доступные инструменты, предлагает более сильную модель и готовит prompt, в котором рабочая модель сама задаёт недостающие предметные вопросы. Скачивание модели-исполнителя пока не подключено.

Каталог Hugging Face остаётся отдельным хранилищем и сервисом, но подключён к сценарию через structured tool `model_catalog_search`. Ядро получает только до шести подходящих карточек, само сравнивает их и при нехватке локальных данных может вызвать живой `hf_find_model`. Выдача учитывает metadata lineage и программную оценку совместимости с RAM/VRAM/диском. Каталог обновляется в фоне не чаще раза в 24 часа; полная база в prompt не загружается.

## Основные документы

- `ROADMAP.md` — актуальные этапы развития;
- `REESTR.md` — зависимости, модели, backends и лицензии;
- `АРХИТЕКТУРА.md` — архитектурные ориентиры;
- `МОДУЛИ.md` — список модулей;
- `ПРАВИЛА_БЕЗОПАСНОСТИ.md` — правила доступа и действий моделей;
- `КАТАЛОГ_ПОВТОРЯЕМЫХ_БАГОВ.md` — известные симптомы и канонические исправления.

Рабочие ТЗ находятся в `H:\AI_HUB\ТЗ`, завершённые — в `H:\AI_HUB\ТЗ\Архив`.

На 2026-07-11 активных ТЗ нет. Визуальный пересмотр сценария и подключение первой рабочей модели остаются будущими отдельными этапами.
