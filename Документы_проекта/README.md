## Краткое описание проекта

AI_HUB — локальный русскоязычный AI-хаб для Windows 11. Его первая цель — дать пользователю удобный нативный интерфейс для каталога, скачивания и хранения локальных ИИ-моделей.

Главная аудитория — пользователь, который интересуется локальным ИИ, но не хочет работать через терминал и ручные инструкции.

## MVP

Первый MVP: визуал + скачивание моделей.

В MVP не входят голос, генерация картинок, музыка, кодинг-режим, browser automation и полноценная RAG-память. Эти части запланированы на будущие этапы.
