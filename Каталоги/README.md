# Каталоги — AI_HUB

Эта папка хранит исходные справочники каталогов проекта. Накопительные пользовательские данные и raw-ответы внешних сервисов сюда не записываются.

## Hugging Face

`huggingface-catalog-seed.json` содержит:

- 11 направлений по 9 слотов;
- роль и уровень нагрузки кандидата;
- точный публичный `repo id`;
- явный признак ручного исключения для специализированных моделей до 8B;
- настройки независимого радара популярных новинок.

Одна модель может занимать несколько тематических слотов. Накопительный каталог объединяет такие слоты в одну запись и сохраняется локально в:

```text
Runtime/Каталоги/HuggingFace/
  catalog.json
  changes.jsonl
  raw/
```

Посевной список является справочником metadata. Модели из него не скачиваются и не поставляются вместе с AI HUB.
